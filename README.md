# River Valley Wound Care Website

A professional, responsive website for River Valley Wound Care practice located in Fort Smith, Arkansas.

## Features

- **Modern Design**: Clean, professional healthcare-focused design
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **FAQ Section**: Interactive accordion-style FAQ with common patient questions
- **Meet the Team**: Showcase of healthcare professionals with photos and bios
- **Location & Hours**: Embedded Google Maps and detailed office hours
- **Contact Form**: Easy-to-use appointment request form with validation
- **Smooth Navigation**: Sticky header with smooth scrolling
- **Accessibility**: Keyboard navigation and focus states for better accessibility

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action
2. **Meet Our Team**: Professional profiles of staff members
3. **FAQ**: Comprehensive answers to frequently asked questions
4. **Location**: Interactive map and detailed location information
5. **Office Hours**: Clear display of operating hours
6. **Contact**: Appointment request form

## Technology

- Pure HTML5, CSS3, and JavaScript
- No frameworks required
- Google Fonts (Montserrat & Open Sans)
- Google Maps embed
- CSS Grid and Flexbox for layout
- Intersection Observer API for scroll animations

## Customization

### Updating Team Members

Edit the team member sections in `index.html` around line 47. Replace placeholder content with actual staff information and photos.

### Modifying Office Hours

Update the hours in `index.html` around line 156 in the office hours section.

### Changing Contact Information

Update phone number and email in the contact section and footer.

### FAQ Content

Add, remove, or modify FAQ items in the FAQ section around line 83.

### Colors

The color scheme can be adjusted in `styles.css` in the `:root` section:

```css
:root {
    --primary-color: #0066cc;
    --secondary-color: #004d99;
    --accent-color: #00a8e8;
    /* ... */
}
```
